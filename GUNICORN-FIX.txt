🔧 WHAT GUNICORN DOES:

Command breakdown:
  gunicorn                    → Production WSGI server
  --worker-class eventlet     → Use eventlet workers (async I/O)
  -w 1                        → 1 worker (free tier)
  --bind 0.0.0.0:$PORT        → Listen on Render's port
  app:app                     → Import app from app.py
